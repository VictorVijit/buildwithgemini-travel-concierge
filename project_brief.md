# My agent: travel-concierge

One-liner: A conversational agent that helps travelers plan personalized trips with a catalog of destinations and activities.

Tool coverage:
- Memory: Remembers traveler preferences, budget, and dietary restrictions
- Tools: Real-time weather lookup and destination info
- Catalog/UI: Collection of hotel & flight recommendations rendered as A2UI cards
- Image gen: Generates destination landscape photos
- Sandbox: Computes budget allocations and currency conversions

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for currency/budget calculations
